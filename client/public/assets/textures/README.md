# Optional photo textures

The game works without anything in this folder (all textures are generated).
To use real photos, add seamless (tileable) images here and list them in
`manifest.json`, for example:

```json
{
  "mud": "mud.jpg",
  "road": "road.jpg",
  "planks": "planks.jpg",
  "zinc": "zinc.jpg",
  "plaster": "plaster.jpg",
  "concrete": "concrete.jpg"
}
```

| Slot | What it should look like |
|---|---|
| mud | wet dark soil with sparse grass, top-down |
| road | muddy dirt road / laterite with tyre ruts, top-down |
| planks | old weathered wooden wall planks (kampung house) |
| zinc | rusty corrugated zinc roof sheet |
| plaster | stained painted plaster wall (old shop) |
| concrete | rough old concrete |

Good free sources (CC0 – no credit needed): ambientcg.com, polyhaven.com.
Use 1K–2K JPGs (≤ 1 MB each). Only use images you have the right to use.
